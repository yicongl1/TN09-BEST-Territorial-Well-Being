# Référentiels d'indicateurs

Deux classeurs construits à partir de sources officielles (INSEE, OCDE, ADEME,
eaufrance, ATMO France, ministères…). Chaque ligne documente un indicateur avec sa
**catégorie**, sa **source**, sa **définition** et sa **méthode de calcul** — de quoi
alimenter un futur outil d'évaluation territoriale.

| Fichier | Contenu |
| --- | --- |
| `indicateurs-systeme-territorial.xlsx` | ~170 indicateurs de durabilité territoriale, organisés par catégories (productivité, croissance, consommation, infrastructures et services urbains, mobilité, logement, santé, éducation, environnement…) |
| `indicateurs-bien-etre.xlsx` | Une vingtaine d'indicateurs couvrant les 11 dimensions du *Better Life Index* de l'OCDE, avec distinction objectif / subjectif |
